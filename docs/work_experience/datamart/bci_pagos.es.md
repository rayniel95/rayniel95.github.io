Este proyecto consistió en desarrollar una plataforma SaaS para el banco chileno BCI. La plataforma permite a los clientes de BCI contratar servicios de Punto de Venta (POS) para sus negocios siguiendo un proceso simple y guiado desde sus dispositivos móviles, donde ingresan su información, especifican el número de terminales POS que necesitan y firman el contrato digitalmente.  
Del lado del banco, una plataforma separada se comunica con la aplicación del cliente. Se utiliza para revisar y aprobar las solicitudes de los clientes, así como para completar la información faltante.  
Mi rol involucró ayudar a implementar ambas plataformas. Desarrollé la infraestructura como código usando AWS y programé la lógica backend usando Fleet, una plataforma interna low-code.
