[Datamart][18371540063288679951] ([Sitio web][11638806455083003844])

##### Equipo:

##### Cliente:

##### Rol:
: Desarrollador backend | Desarrollador cloud

*Junio, 2022 – Julio, 2022*

La Habana, Cuba

Este proyecto está relacionado con aumentar las funcionalidades del sistema de Falabella Bank en Chile. La idea básica de este proyecto fue crear una plataforma SaaS que pudiera ser usada por los empleados de Falabella. Mi trabajo fue crear las funcionalidades para transformar algunos documentos digitales en otros usando filtrado y fusión de esos documentos. La arquitectura del sistema ya estaba creada. No tenía mucha experiencia sobre cómo implementar las tareas solicitadas pero gracias a mi excelente educación en la Universidad de La Habana y mi rápida capacidad de aprendizaje pude aprender sobre AWS Lambda functions, AWS Step Functions, Serverless Framework y otras tecnologías de AWS y cloud implementando todas las tareas necesarias.

### Logros técnicos

- Implementé una función AWS Lambda para mapear documentos JSON a otros datos.
- Usé funciones AWS Lambda para implementar las funcionalidades del backend.
- Implementé AWS Step Functions usando Serverless Framework y el plugin de Step Functions.
- Implementé Event Rules para las step functions, conectando la step function a AWS EventBridge.
- Añadí capacidades de logging a las step functions ayudando a ver todo el trace de ejecución de la step function en AWS CloudWatch.
- Dividí el código serverless (código de serverless framework y cloud formation) en múltiples archivos para mejorar la organización, legibilidad y calidad del código.
- Usé AWS SSM para leer y almacenar parámetros y garantizar el paso de parámetros entre AWS Stacks.
- Usé el modelo de branching de git flow para obtener una mejor organización en el desarrollo del proyecto.
- Usé la librería GQL de Python para consultar servicios de AWS Appsync obteniendo múltiples documentos JSON.
- Usé la feature de list comprehension de Python para mapear documentos JSON a otros datos, mejorando la calidad y legibilidad del código.
