- Investigué la factibilidad de aplicar el framework blockchain Substrate para crear una blockchain permissioned.
- Investigué la factibilidad de usar Solidity y la Ethereum Virtual Machine (EVM) para crear smart contracts para una blockchain permissioned basada en nodos Substrate.
- Formé a estudiantes de informática enseñando la teoría detrás de blockchain, las plataformas blockchain más usadas (Ethereum, Hyperledger Fabric, Substrate) y cómo trabajar con ellas.
- Trabajé directamente en seminarios proporcionados por la Universidad con el objetivo de divulgar los beneficios de Blockchain para la Economía.
- Asistí a cursos de Maestría de "Introducción a Blockchain" y "Temas Avanzados de Blockchain" de universidades extranjeras.
- Diseñé e implementé el proyecto RainyelCert, una red blockchain permissioned usando el framework Substrate para la firma y almacenamiento de certificados.
