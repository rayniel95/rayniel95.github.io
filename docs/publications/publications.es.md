## **[Sistema blockchain para el almacenamiento de historias clínicas.][4679700590590758308]**

*Septiembre 2020*

**[www.researchgate.net][16275601580485639132]**

El sistema de salud cubano trabaja con historias clínicas físicas, se han realizado algunos esfuerzos para digitalizar las historias clínicas pero usando bases de datos centralizadas. En mi proyecto de tesis de pregrado implementé un prototipo funcional para el almacenamiento electrónico de historias clínicas usando Hyperledger Fabric. En este documento se explican los detalles sobre este proyecto. Este sistema es una línea base de solución para el problema del almacenamiento electrónico de historias clínicas en Cuba. La solución final será una red blockchain nacional con datos cifrados para la privacidad.

- Investigué la teoría detrás de la tecnología blockchain.
- Analicé algunas plataformas y tecnologías blockchain como: Bitcoin, Ethereum, HashGraph, Hyperledger Fabric, BigChain, Corda, Quorum.
- Analicé en profundidad la arquitectura de Hyperledger Fabric.
- Expliqué las diferencias entre blockchains privadas, permissioned y públicas.
- Se analizaron diferentes aplicaciones de blockchains como: blockchain en juegos, blockchain en votación electrónica, blockchain e inteligencia artificial, blockchain en la cadena de suministro, etc.
- Analicé proyectos similares.
- Investigué y expliqué los estándares de historias clínicas digitales más utilizados.
- Investigué y expliqué el estándar Observational Medical Outcomes Partnership (OMOP).
- Creé una estructura de código organizada para el sistema.
- Propuse, diseñé y expliqué un smart contract para almacenar historias clínicas en formato OMOP.
- Propuse, diseñé y expliqué una aplicación web para interactuar con la red blockchain.
- Propuse, diseñé y expliqué una arquitectura de red blockchain para el almacenamiento de historias clínicas usando Hyperledger Fabric.
- Propuse un método de autenticación descentralizado sobre Hyperledger Fabric.
- Propuse un método de cifrado híbrido para el cifrado de historias clínicas.
